# XP Demagnetization

Unofficial fix for [Simple Magnets](https://www.curseforge.com/minecraft/mc-mods/simple-magnets)'s
Demagnetization Coil not affecting experience orbs.

## What it does

The Demagnetization Coil excludes item entities from magnet pickup, but not
experience orbs — see [SimpleMagnets#71](https://github.com/SuperMartijn642/SimpleMagnets/issues/71).
This mod extends the same exclusion zone to XP orbs.

## Requirements

- Simple Magnets (required, not bundled)
- NeoForge 1.21.1
